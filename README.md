# Franklin Township Interfaith Council Website

This is the rebuilt website for Franklin Township Interfaith Council.

Primary domain:

- `franklintwpinterfaith.org`

The project is built with Vinext and is prepared for OpenAI Sites hosting.

## Content Notes

- The approved logo assets are copied from `../logos/`.
- Old site files and screenshots remain outside this folder as reference material.
- Passed event announcements from the old site should not be shown as current events.
- Current officer, donation, partner, and contact details should be confirmed before public launch.

## Local Commands

```bash
npm run dev
npm run build
npm test
```
